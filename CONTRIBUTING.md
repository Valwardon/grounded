# Contributing to Grounded

Thank you for your interest in Grounded! This project is open to anyone who
wants to help build a deterministic, symbolic cognitive engine.

## How to contribute

1. Fork the repository
2. Create a feature branch
3. Implement your idea or improvement
4. Submit a pull request with a clear description

## Coding guidelines

- Keep modules small and composable
- Follow the existing architecture style
- Document new nodes, relations, or modules
- Add tests for new functionality

## Good first issues

Check the Issues tab for tasks labeled “good first issue”.
